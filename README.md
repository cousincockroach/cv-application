# 📄 Interactive React CV Application

A dynamic, component-driven web application built with React that allows users to create, edit, and preview a professional curriculum vitae (CV) in real-time. Designed to separate data input from document formatting, this app provides instant visual feedback as users update their personal, educational, and professional experience.

[Live Link ](https://tapz-cv-builder.netlify.app/)

---

## ✨ Features

* **Real-Time Preview Synchronization:** As you type your details into the input forms, the CV document updates instantly to reflect your changes.
* **Edit & Submit Mode Toggle:** Switch seamlessly between editing mode (forms active) and preview mode (clean, professional print-ready document view).
* **Modular Component Architecture:** Cleanly separated components for General Information, Educational Experience, and Practical Work Experience.
* **State Management:** Effectively lifts state up from child input components to maintain a centralized application state model.
* **Responsive Professional Styling:** Styled with modern CSS to ensure the final CV layout looks crisp, balanced, and ready for export.

---

## 🛠️ Tech Stack

* **Frontend Library:** React (Functional components, Hooks: `useState`)
* **Styling:** Vanilla CSS3 (Flexbox, CSS variables, print-friendly layout styles)
* **Build Tooling:** Vite / Create React App environment, npm, Git/GitHub
